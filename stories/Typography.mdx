# Typography

Two faces, clear division of labor. **JetBrains Mono** is the brand voice —
wordmark, headings, labels, code, numbers. The **system sans** carries body
text so the mono stays special. Never set long-form prose in the mono.

## Rules

- Headings in mono get tight tracking; uppercase labels get wide tracking — never both at once
- Tabular numerals (`font-variant-numeric: tabular-nums`) wherever digits align in columns
- The wordmark is typography: lowercase `overcast`, mono bold, tracking −0.02em — never recreate it casually; use the lockup SVGs
