# Color

The palette is navy-grounded with one accent — **Signal** — that always swaps
with the surface: `#1273C4` on light grounds, `#5FB8FF` on dark. Never use the
dark-surface accent on white; it fails contrast. Neutrals are hue-biased toward
the brand blue — never pure grey.
