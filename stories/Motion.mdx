# Motion

One animation is sanctioned: **the blinking cursor** — 1.1s, hard steps (no
easing, like a real terminal). It appears in loading states and nowhere else.
Everything else moves at most 120ms ease-out on hover, and nothing moves for
users with `prefers-reduced-motion`.

## CSS

```css
/* from design-system/tokens.css */
@keyframes oc-blink { 0%, 49.9% { opacity: 1; } 50%, 99.9% { opacity: 0; } }
.oc-cursor-blink { animation: oc-blink var(--oc-blink) steps(1) infinite; }
@media (prefers-reduced-motion: reduce) { .oc-cursor-blink { animation: none; } }
```

Tailwind: `animate-oc-blink` (from the preset / @theme tokens).
