# Logo & marks

## Lockup

The wordmark is always lowercase **overcast**, bold, in the brand mono.
The tagline is optional below 160px width — drop it rather than shrink it.

## The mark

Clearspace = the chevron's height (≈ 0.4 × cloud height) on all sides.
Minimum size: 24px bare, 16px tiled.

## Usage

<Do good>Use the tiled icon whenever the background is unknown or busy.</Do>
<Do good>Use mono marks for stickers, engraving, single-color print.</Do>
<Do good={false}>Don't rotate, outline, shadow, or gradient-fill the mark.</Do>
<Do good={false}>Don't scale large SVGs down — use the per-size icons.</Do>
<Do good={false}>Don't set the wordmark in a proportional font or capitalize it.</Do>
<Do good={false}>No orange, no radio/sound waves — that's Overcast.fm's territory.</Do>
