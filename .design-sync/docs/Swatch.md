# Swatch

A color specimen: a fixed-width tile showing the color itself above its name, hex value (in the brand mono), and usage note.

```tsx
<Row>
  <Swatch name="Accent / light" hex="#1273C4" use="signal on light surfaces" />
  <Swatch name="Accent / dark" hex="#5FB8FF" use="signal on dark surfaces" />
</Row>
```

- Compose several in a `Row` to present a palette.
