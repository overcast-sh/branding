# Do

A do/don't rule line: a mono ✓ (success color) or ✗ (danger color) followed by the rule text. The brand book uses stacks of these for usage guidance.

```tsx
<Do good>Use the tiled icon whenever the background is unknown or busy.</Do>
<Do good={false}>Don't rotate, outline, shadow, or gradient-fill the mark.</Do>
```
